# Rootfs feature:

```shell
Manage root filesystem

USAGE
  rootfs

COMMANDS
  clone           Set up rootfs directory in workspace
  build           Build root filesystem
  show            Show rootfs build result
  clean           Remove root filesystem

FLAGS
  --help-all  Show all help

Use "rootfs [command] --help" for more information.
```

# Issues:
- `show` command is different from `status` command. For more details, please refer to the `WORKFLOW.md` file.
