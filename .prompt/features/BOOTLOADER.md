# Bootloader feature:

```shell
Build and configure bootloader (U-Boot)

USAGE
  bootloader

COMMANDS
  clone           Clone U-Boot repository
  config          Configure bootloader for current architecture
  build           Build bootloader
  show            Show bootloader build result
  clean           Clean bootloader build artifacts

FLAGS
  --help-all  Show all help

Use "bootloader [command] --help" for more information.
```

# Issues:
- `status` command is missing for bootloader, which should show the current status of the bootloader build and whether it is ready to be used for running the kernel. This is different from the `show` command which shows the detailed information of the built bootloader image and any build errors or warnings. For more details, please refer to the `WORKFLOW.md` file.
- `show` command is different from `status` command. For more details, please refer to the `WORKFLOW.md` file.
- `build` command got some problems when building bootloader although the final building process is successful, please check and resolve the issues to ensure a smooth user experience. So, I asked the Claude AI and it gave me this solution: export the OpenSSL libraries path
```shell
# Check OpenSSL installation path
brew --prefix openssl@3

# Integrate these paths into elmos package
export OPENSSL_DIR=$(brew --prefix openssl@3)
export PKG_CONFIG_PATH="${OPENSSL_DIR}/lib/pkgconfig:${PKG_CONFIG_PATH}"
export CPPFLAGS="-I${OPENSSL_DIR}/include ${CPPFLAGS}"
export LDFLAGS="-L${OPENSSL_DIR}/lib ${LDFLAGS}"
```
